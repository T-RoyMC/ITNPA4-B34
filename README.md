# ITNPA4-B34
Project 1

This project classifies research abstracts as ai or classical using a TF-IDF + machine-learning pipeline (Questions 1–2, with a Streamlit app and HTML for deployment in deployment), then builds a small 5-article document corpus that  summarizes two ways — a frequency-based TF-IDF extractive summary of one article and a TextRank graph-based extractive summary aggregated across the rest and topic-models with LDA, visualized both statically and as an interactive pyLDAvis map (lda_vis.html) (Questions 3–4). The following libraries are requires so pip install the usual stack (pandas, scikit-learn, nltk, matplotlib, seaborn, networkx, pyLDAvis) and run all cells.
